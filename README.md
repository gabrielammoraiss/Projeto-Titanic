# Análise Exploratória dos Passageiros do Titanic

## Sobre o projeto

Este projeto realiza uma análise exploratória dos dados dos passageiros do Titanic com o objetivo de investigar como características demográficas e socioeconômicas influenciaram as taxas de sobrevivência no desastre.

A análise foi desenvolvida como parte dos estudos do curso de **Ciência de Dados para Negócios da FATEC Votorantim**.

## Pergunta de análise

Quais características dos passageiros estão relacionadas a uma maior ou menor probabilidade de sobrevivência?

Foram analisadas variáveis como:

- Sexo;
- Idade;
- Classe da passagem;
- Valor da tarifa;
- Número de familiares a bordo;
- Porto de embarque;
- Status de sobrevivência.

## Objetivos

- Conhecer e explorar a estrutura da base de dados;
- Identificar informações ausentes e possíveis inconsistências;
- Realizar a limpeza e a preparação dos dados;
- Analisar a relação entre as características dos passageiros e a sobrevivência;
- Criar visualizações para facilitar a interpretação dos resultados;
- Desenvolver uma conclusão baseada nos dados.

## Tecnologias utilizadas

- Python;
- Jupyter Notebook;
- Pandas;
- NumPy;
- Matplotlib;
- Seaborn.
